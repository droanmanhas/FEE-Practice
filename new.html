About My Website

Welcome to my simple website. This page is created using basic HTML and CSS.

HTML is used to create the structure of the webpage, while CSS is used to design and style the different sections.

The website contains a large background image which gives the page an interesting appearance.

One interesting feature of this webpage is the fixed background image.

When we scroll down, the content moves while the background image stays in place.

This is done using the CSS property background-attachment.

This project helped me understand HTML sections, background images, colors, spacing and basic CSS.

Thank You For Visiting!
